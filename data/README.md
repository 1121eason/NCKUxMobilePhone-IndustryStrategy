# Published aggregate results

`published-summary.json` contains selected numerical summaries transcribed from source S1, printed pp. 383, 387–388. It is not a project-level dataset and must not be presented as data collected by the repository owner.

Conventions:

- CDR: brand firm's relative concept-level decision rights.
- IDR: contract manufacturer's relative implementation-level decision rights.
- PDP: centered product development performance assessment; not a percentage.
- Quadrant labels follow the paper: I upper left, II upper right, III lower left, IV lower right.
- A missing regression term means it was not included in that model.
- `stars` follows Table 3; `*` means p < .10, `**` p < .05 and `***` p < .01. An empty marker does not mean zero effect.
- Model p-values preserve the published display precision. `0.000` is a printed value, not a claim of an exact zero probability.
- Rounded summaries are insufficient to recover the original observations or reproduce the authors' regression.

For interpretation and inconsistencies between the table and narrative, see the [evidence review](../docs/evidence-review.md).
